# 拍摄指向先验：A/B 与消融实验

这是 0.5.7「指向先验」解算路径的验收基准。用一张真实的 83° 视场手机广角照片（本机解算整幅解不出，astrometry.net 的 WCS 当真值），逐项关掉先验的组成部分，看还能不能解出来。

## 协议

- 图像：`build/repro/starfield_fail.jpg`（1600×2133，分析层 900×1200，视场 83.1°，含二阶 SIP 畸变）；
- 真值：astrometry.net 解出的 WCS（中心 330.52°, 49.39°，roll 83.5°，尺度 0.0677°/px）；
- 「先验」按现实误差生成：中心偏 1°/3°/5°/10°，滚转差 0.5°（IMU 重力方向通常 0.1–0.5°），视场差 3%（EXIF 35mm 等效焦距的典型误差）；
- 每个变体跑 `PlateSolver.solve`，记录：是否解出、耗时（JIT 测试机）、内点数、中心误差、视场；
- 失败变体给 1.5 s 预算快速失败（否则默认广域路径会再跑几分钟分块解算）。

## 结果（2026-11-07）

| 变体 | 解出 | 耗时 | 内点 | 中心误差 |
| --- | --- | --- | --- | --- |
| 无先验（默认路径） | ✗ | — | — | — |
| 仅中心 3° | ✗ | — | — | — |
| 中心 3° + 视场（EXIF） | ✗ | — | — | — |
| 中心 3° + 滚转（IMU） | ✓ | 5.6 s | 428 | 0.07° |
| 中心 3° + 滚转 + 视场 | ✓ | **1.7 s** | 427 | 0.07° |
| 中心 1° + 滚转 + 视场 | ✓ | 1.5 s | 428 | 0.07° |

| 中心 10° + 滚转 + 视场 | ✓ | 7.6 s | 427 | 0.07° |
| 中心 3° + 滚转差 2° | ✓ | 1.6 s | 427 | 0.08° |
| 中心 3° + 视场差 6% | ✓ | 1.8 s | 427 | 0.07° |
| 先验错 30°（必须拒绝） | ✗ | — | — | — |

曲率消融（同一真值 WCS，只开/关 SIP）：

| 模型 | 2.5 px 内匹配 | 残差中位数 |
| --- | --- | --- |
| 纯 TAN | 126 / 731 | 7.5 px（30.5′） |
| + 二阶 SIP | **406 / 731** | **1.9 px（7.6′）** |

解出结果的标注精度：与 astrometry.net 真值逐像素比，平均角差 **2.4′**。

## 结论

- 中心先验单独不够（不知道滚转/视场时，粗网格对不上边角）；
- **滚转是关键**：有了 IMU 的重力方向，即使视场未知也能解（慢一些）；再加上 EXIF 视场就进入 1–2 s；
- 先验错 30° 不会硬凑解——最终验收是 100 颗 3 px 内点的硬门槛（错误先验最多凑到 42 颗，随机水平）。
